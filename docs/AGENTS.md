LearnLoop Agent Instructions

LearnLoop is a collaborative student learning ecosystem.

Core philosophy:

- contribution over popularity
- collaboration over isolation
- trust over vanity metrics
- AI supports humans, not replaces them

Tech stack:

- Next.js
- TypeScript
- Tailwind
- shadcn/ui
- Supabase
- Prisma

Rules:

- Maintain modular architecture
- Never break existing systems
- Use reusable components
- Dark mode first
- Mobile responsive
- Clean scalable code
- Strong TypeScript typing
- Accessibility support
- Avoid duplicated logic

UI style:

- Linear + Discord + Notion hybrid
- calm dark mode
- modern spacing
- soft gradients
- subtle animations

Never:

- generate messy architecture
- create unnecessary complexity
- overuse animations
- create social-media addiction patterns
